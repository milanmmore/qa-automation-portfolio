# 🤖 30 Days of AI for Testers & Automation Engineers  
### Learn how to use Claude, ChatGPT, Gemini & Copilot for every QA task

This repository is a complete 30‑day learning program designed for testers, QA engineers, and automation engineers who want to master **AI‑powered testing** using modern LLMs:

- **Claude** (deep reasoning, long logs, test planning)  
- **ChatGPT** (best coding model for automation + API testing)  
- **Gemini** (best for documents, PDFs, Sheets, screenshots)  
- **Copilot** (best inside VS Code + GitHub for automation coding)

Each day includes:
- What you will learn  
- Which LLM to use  
- Why that LLM is the right choice  
- Hands‑on tasks  
- Portfolio‑ready deliverables  

This is the most practical, modern QA learning roadmap available.

# 🧠 Why This Program?

Modern QA requires more than manual test cases and basic automation.  
AI tools can now:

- Generate test plans  
- Write automation scripts  
- Debug failing tests  
- Analyze logs  
- Create CI/CD pipelines  
- Summarize requirements  
- Produce documentation  

This program teaches you **exactly how to use each LLM for the right QA task**.
